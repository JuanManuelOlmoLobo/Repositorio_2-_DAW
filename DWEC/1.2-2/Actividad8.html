1. JavaScript es un lenguaje de programación diferente a Java.

2. Las hojas de estilo de una página web se guardan en archivos con extensión .js.

3. El método 'document.getElementById()' sirve para seleccionar un elemento del HTML por su ID.

4. En JavaScript, los meses del objeto Date() empiezan a contar de forma natural desde el número 1 para Enero.

5. El método 'padStart(2, "0")' se puede aplicar únicamente sobre cadenas de texto (Strings).

6. HTML es un lenguaje de programación estructurado que compila binarios en tiempo de ejecución.

7. El atributo 'defer' en una etiqueta de script hace que este se ejecute una vez cargado todo el documento HTML.
